# matplotlib

A skill to write clean [Matplotlib](https://matplotlib.org) code in Python: object-oriented API, themes with `rcParams`, text and annotations, layouts, export and debugging.

It covers the **coding side only**. Chart design (chart type, color, annotation) is handled by the other skills of this repo.

## 📚 Based on the Matplotlib Journey course

This skill comes from [**Matplotlib Journey**](https://www.matplotlib-journey.com), a course by [Joseph Barbier](https://github.com/JosephBARBIERDARNAL) and [Yan Holtz](https://www.yan-holtz.com). Hundreds of free examples are also available in the [Python Graph Gallery](https://python-graph-gallery.com).
