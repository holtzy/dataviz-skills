# roast-my-chart

A skill that reviews a finished chart against the 61 [Data to Viz caveat flashcards](https://github.com/holtzy/dataviz-caveat-flashcards), and tells you what to fix, with a link to the matching card.

Give it an image, plotting code (ggplot2, Matplotlib, D3…), or both. It checks every caveat, flags only what it actually sees in your chart, and offers to fix the code.

![Dataviz caveat flashcards laid out on a table](https://raw.githubusercontent.com/holtzy/dataviz-caveat-flashcards/main/overview/grid.jpg)
