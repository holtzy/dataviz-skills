# gribouille

A skill to write clean, idiomatic [Gribouille](https://typst.app/universe/package/gribouille) code in Typst: the `#plot()` call shape, grouping through `aes()`, themes, scales, legends, facets and export.

It covers the **coding side only**. Chart design (chart type, color, annotation) is handled by the other skills of this repo.

## 📚 Based on the Gribouille documentation

This skill comes from the [Gribouille documentation](https://m.canouil.dev/gribouille/) and the [Gribouille gallery](https://m.canouil.dev/gribouille/gallery/), both by [Mickaël Canouil](https://mickael.canouil.fr).
