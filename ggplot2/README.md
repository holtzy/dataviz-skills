# ggplot2

A skill to write clean, idiomatic [ggplot2](https://ggplot2.tidyverse.org) code in R: tidyverse conventions, themes, scales, legends, faceting and export.

It covers the **coding side only**. Chart design (chart type, color, annotation) is handled by the other skills of this repo.

## 📚 Based on the ggplot2 Uncharted course

This skill comes from [**ggplot2 Uncharted**](https://www.ggplot2-uncharted.com), a course by [Cédric Scherer](https://www.cedricscherer.com) and [Yan Holtz](https://www.yan-holtz.com). Hundreds of free examples are also available in the [R Graph Gallery](https://r-graph-gallery.com).
