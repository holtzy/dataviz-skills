# d3

A skill to build charts with [D3.js](https://d3js.org) **in a React application** (React, Next.js, Vite, Remix…).

## ⚛️ This skill expects you to work with React

The skill does not teach "vanilla" D3, where D3 selects and manipulates the DOM (`d3.select().append()…`). It follows a different approach, best suited to modern web apps:

- **D3 does the math**: scales, shape generators, layouts, data helpers.
- **React does the rendering**: SVG elements are written in JSX, state and interactions are handled with hooks.

If your project doesn't use React, this skill is probably not what you need.

## 📚 Based on the D3 Loves React course

The content of this skill is based on the concepts taught in [**D3 Loves React**](https://www.d3-loves-react.com), a complete course on building interactive charts with D3 and React.

Want to go further than what an AI agent can do for you? The course walks you through each concept step by step, with exercises and dozens of real-world chart examples. Hundreds of free examples are also available in the [React Graph Gallery](https://www.react-graph-gallery.com).
